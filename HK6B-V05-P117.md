# HK6B — DM-32UV: cumulative development through V05 P117

**This document describes the cumulative HK6B firmware and the scope of the public P117 source selection.** Previous NXDN and UI developments remain integrated in the operator's latest firmware. The public repository does **not** contain all related sources.

## Chronology (cumulative, not independent builds)

| Milestone | Work preserved in later versions | Evidence |
| --- | --- | --- |
| Early HK6B V01–V03 | Audio, display and UI refinements | Earlier development history |
| **V03E** | NXDN source-ID display and reception/reconstruction of OAA aliases on the radio UI | Physically verified by operator |
| **V04** | Separate **last-three NXDN callers** display with aliases/IDs, call destination/context and deduplication; in-memory history | Physically verified by operator |
| **V05 P115** | Four shared Motorola Basic Privacy key slots, per-channel slot selection and persistence | Physically verified by operator |
| **V05 P116** | Editing BP association/slot on the radio; warning for shared key settings and persistence after restart | Physically verified by operator |
| **V05 P117** | CPS Web Serial protocol to read/write the four shared BP slots, with confirmation and re-read | Physically verified by operator |

The cumulative firmware also retains RadioFoundry functionality and NXDN 4800/9600-related support. Later stages **do not supersede or remove** NXDN/OAA or history functionality.

## Source components: full firmware versus this public snapshot

### Full cumulative firmware (not fully published here)

- `core/nxdn/nxdn_call.c` — NXDN/OAA reception and alias reconstruction.
- `core/radio/radio_nxdn.c` and `.h` — radio-view identification and alias.
- `core/ui/ui_app.c`, `core/ui/ui_screens.c`, `core/ui/ui_screens.h` — NXDN recent-caller state and presentation (up to three entries).

These are **not all included in this public subset**; no inference should be made that they are absent from the working firmware.

- `core/radio/hk6b_privacy_cache.h`
- `core/radio/hk6b_privacy_effective.h`
- `core/radio/hk6b_privacy_guard.h`

- Selected CPS JavaScript in `site/static/js/`.

**Scope:** technical reference for maintainers, not an independently buildable firmware or complete CPS deployment. It is not a complete patch against current upstream `main`. The full HTML/CSS/generated CPS site, installed radio image, codec and recovery package are excluded.

## Physical verification and boundaries

The owner confirms that the combined P117 firmware works on their own Baofeng DM-32UV, including the earlier NXDN caller identification/OAA/history functionality, BP slot selection and CPS BP read/write, with settings preserved through restart. This is operator-reported physical validation, **not** an automated all-board test or certification of every Dual Watch / simultaneous-call transition.

If an upstream contribution is requested, first prepare small patches against the appropriate upstream baseline with reproducible host/CI tests. Do not rewrite or remove the already working cumulative firmware merely to prepare the patches.
